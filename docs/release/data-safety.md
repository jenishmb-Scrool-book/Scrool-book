# Data Safety — готовые ответы для Play Console

Форма заполняется в Play Console → «Безопасность данных». Ответы ниже
соответствуют коду на момент редакции. **Если приложение начнёт обращаться
к сети — форму и политику надо переписать до выпуска той версии**, иначе это
уже нарушение, а не неточность.

Форма спрашивает про **сбор** (данные уходят с устройства) и **передачу**
(данные уходят третьим лицам). Данные, которые лежат только на устройстве и
никуда не отправляются, сбором не считаются — это прямо оговорено в правилах.
У приложения нет разрешения `INTERNET`, так что отправить что-либо оно и не
может.

## Основные ответы

| Вопрос | Ответ |
|---|---|
| Собирает ли приложение данные пользователей? | **Нет** |
| Передаёт ли данные третьим лицам? | **Нет** |
| Шифруются ли данные при передаче? | Вопрос не появится: передачи нет |
| Есть ли способ запросить удаление данных? | **Да**, удалением приложения или очисткой данных |
| Прошло ли приложение независимую проверку безопасности? | Нет |

Раздел «Типы данных» после ответа «не собирает» останется пустым.

## Что отвечать, если спросят отдельно

**Файлы и документы.** Пользователь сам открывает файл книги или изображение
для обоев через системное окно выбора. Приложение хранит копию в своём личном
хранилище и никуда её не отправляет. Сбором это не является.

**Идентификаторы.** Не используются вообще: ни рекламного ID, ни Android ID,
ни собственных идентификаторов устройства.

**Аналитика и сбои.** Не подключены. Никаких SDK, кроме плагинов Capacitor,
которые работают локально.

## Возрастной рейтинг (анкета IARC)

| Вопрос | Ответ |
|---|---|
| Насилие, секс, наркотики, азартные игры, ненормативная лексика | Нет |
| Пользовательский контент, обмен между пользователями | Нет |
| Обмен местоположением | Нет |
| Покупки внутри приложения | Нет |
| Реклама | Нет |

Ожидаемый результат: рейтинг «для всех» / 3+. Целевую аудиторию при этом
указываем **13+**: приложение не для детей, и в политике это сказано прямо.

## Категория и заявления

Категория — «Книги и справочники».

Название приложения диагноза не называет. Прежнее называло — это была
аббревиатура СДВГ, и она сама по себе притягивала проверку на медицинские
заявления. Проверку переименование не отменяет: описание всё так же про
внимание и про привычку листать. Поэтому в карточке нигде не говорится,
что приложение лечит, диагностирует или облегчает СДВГ, — только что оно
сделано с оглядкой на такой способ читать. Формулировки в `store-listing.md` подобраны так
намеренно; менять их на «помогает при СДВГ» не стоит, это уже заявление
о медицинском эффекте.
