# Закрытый тест — где взять 12 человек и что им писать

Правило Google для личных аккаунтов: в продакшен пускают, когда в закрытом
тесте **не меньше 12 человек подписаны 14 суток подряд**. Отписался один —
его срок начинается заново, поэтому зовём 15–20.

## Порядок

1. ~~Группа Google~~ — создана 6 октября: `scrollbook-testers@googlegroups.com`.
2. ~~Закрытая дорожка «Alpha»~~ — настроена и сохранена в «Обзоре публикации»:
   177 стран, тестировщики — эта группа, почта для отзывов — из политики.
   Выпуска в ней пока нет.
3. **Владелец:** «Контент приложения» (ответы — `checklist.md`, 1.4) и
   категория с контактной почтой. Пока они не заполнены, Play не даёт
   создать выпуск в закрытой дорожке: на панели управления она закрыта
   замком.
4. **Владелец:** собрать версию 3 (1.0.2), в закрытом тестировании
   «Создать выпуск» → загрузить `.aab`, затем «Обзор публикации» →
   «Отправить изменения на проверку». Новое приложение Google проверяет от
   нескольких часов до нескольких дней.
5. Пока идёт проверка — посты. Ссылку не даём, просим отозваться: она
   заработает только после проверки.
6. Проверка прошла — всем, кто отозвался, инструкция ниже.
7. Через 14 суток с двенадцатого подписавшегося — заявка на продакшен.

Версию 3 (Clips, отзыв, вторая книга) можно выпустить обновлением прямо во
время теста: срок от обновления не сбрасывается.

## Группа Google — создана

Адрес: `scrollbook-testers@googlegroups.com`, страница для вступления —
<https://groups.google.com/g/scrollbook-testers>. Настройки выставлены и
проверены в «Настройках группы»:

| Настройка | Значение | Зачем |
|---|---|---|
| Кто может видеть группу | все | иначе не вступить по ссылке |
| Кто может вступить | кто угодно, без одобрения | не разбирать заявки по одной |
| Кто может просматривать обсуждения | участники группы | |
| Кто может создавать записи | администраторы групп | чтобы не было спама |
| Кто может просматривать список участников | администраторы групп | **тестировщики не видят друг друга** |

Участников в неё не добавляют: каждый вступает сам. Так не нужно собирать
почты и вписывать их руками.

Через группу же можно написать всем сразу: письмо в группу приходит каждому
на почту.

## Инструкция тестировщику — когда проверка пройдёт

Подставить адрес группы.

```
Спасибо, что помогаете! Три шага, минуты на две:

1. Вступите в группу: https://groups.google.com/g/scrollbook-testers → «Вступить в группу». Важно: тем же аккаунтом Google, что в Play Маркете на телефоне.
2. Откройте https://play.google.com/apps/testing/com.tirekai.scrollbook → «Стать тестировщиком».
3. Установите: https://play.google.com/store/apps/details?id=com.tirekai.scrollbook

Если пишет, что приложение недоступно, — подождите 10–15 минут после вступления в группу и откройте ссылку из пункта 2 ещё раз.

Пожалуйста, 14 дней не удаляйте приложение и не выходите из теста. Нашли ошибку или есть идея — пишите мне.
```

Своя книга не обязательна: с версии 3 в библиотеке есть кнопка «Взять
„Капитанскую дочку“» (на английском — «Алиса»). Если в закрытом тесте ещё
версия 2, в инструкции стоит сказать, что книгу нужно принести свою — `.fb2`,
`.epub` или `.txt`, или вставить текст.
