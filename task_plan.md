# Скролл — читалка в виде телефона

## Goal
Читалка для людей с СДВГ / привыкших к вертикальному контенту.
Пользователь вставляет свой текст (книгу), приложение показывает его как
экран телефона с «приложениями»: чаты, клипы, лента, видео.
Один и тот же текст, разные обёртки, общий прогресс чтения.

## Core insight
Текст режется на чанки один раз. Есть один курсор `pos`.
Каждое «приложение» — это просто другой рендерер пары (chunks, pos).
Переключился с клипов на чаты — продолжил с того же места.

## Decisions Made
| Решение | Почему |
|---|---|
| Один HTML-файл, без фреймворка | Нечего собирать, открывается двойным кликом, легко переносится в PWA/Capacitor потом |
| localStorage, не IndexedDB | Лимит ~5 МБ хватает на книгу; IndexedDB — когда упрёмся |
| Общий курсор для всех «приложений» | Это и есть фича продукта, а не 4 отдельные читалки |
| Свои названия вместо WhatsApp/TikTok | Товарные знаки; вёрстка всё равно узнаваемая |
| Без EPUB | Нужна библиотека для zip; .txt/вставка покрывают старт |

## Errors Encountered
| Error | Attempt | Resolution |
|---|---|---|
| Агенты «экраны» и «Android» упали на лимите сессии (429) | 1 | Не перезапускал: код уже лежал на диске почти целиком. Доделал сам — дешевле холодного агента |
| `Library.jsx`: `.catch()` на `addBook` не срабатывает | 1 | `addBook` резолвится в `null`, а не реджектится. Решение по `id` |
| `Library.jsx`: `setText('')` до сохранения | 1 | Текст терялся при переполнении. Чистка поля перенесена в ветку успеха |
| Демо-текст первого запуска потерян при порте | 1 | `src/seed.js` + эффект в `App.jsx` (не в сторе — там 18 тестов) |
| Скриншотилка браузера трижды отвалилась по таймауту | 3 | Проверял через замеры DOM; `zoom` в итоге снял корректный кадр |
| Весь скрипт падал на первой строке | 1 | `localStorage` бросает SecurityError на opaque origin (превью, приватный режим) — обёртка LS с фолбэком в память |
| `open()` в inline-onclick стирал страницу | 1 | В inline-обработчиках `open` резолвится в `document.open` — переименовано в `openBook` |
| IntersectionObserver не двигал курсор | 2 | Заменён обычным scroll-хендлером: карточка ровно в высоту экрана, наблюдатель избыточен |
| sed-якорь совпал с CSS-комментарием, файл раздублировался | 1 | Файл перезаписан целиком; впредь якоря только уникальные |
| Промах скролла на ~81px в ленте/видео | 1 | `offsetTop` считался от `.screen`; добавлен `position:relative` на `.body` |
